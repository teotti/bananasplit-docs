```
banana <command> [--json | --raw]
```

## Balances

```bash
banana balance              # Show the aggregate balance
banana balance users        # Show balances by user
banana balances             # Alias for `balance users`
```

## Expenses

```bash
banana expenses list                  # List your expenses
banana expenses add                   # Add an expense
banana expenses get <expense-id>      # Show an expense
banana expenses edit <expense-id>     # Edit an expense
banana expenses delete <expense-id>   # Delete an expense
banana expenses restore <expense-id>  # Restore a deleted expense
```

### Adding expenses

```bash
banana expenses add --title "Dinner" --amount 42 --currency EUR \
  --paid-by me --date 2026-09-01 --group "Lisbon trip" \
  --split me=22 --split Ana=20
```

| Flag | Description |
|------|-------------|
| `--title` | Expense description |
| `--amount` | Total amount |
| `--currency` | Currency code (EUR, USD, etc.) |
| `--paid-by` | Who paid (name or `me`) |
| `--date` | Date (YYYY-MM-DD or DD-MM-YYYY) |
| `--group` | Group name (optional) |
| `--split` | Split amount per person (repeatable) |
| `--split-type` | `equal` or `custom` |
| `--notify-me` | Send push notification to yourself |

### Listing expenses

```bash
banana expenses list --limit 10
banana expenses list --sort amount --direction desc
banana expenses list --group "Lisbon trip"
banana expenses list --recurring
banana expenses list --no-recurring
```

## Recurring expenses

```bash
banana recurring list              # List recurring expense rules
banana recurring add               # Add a recurring expense rule
banana recurring get <rule-id>     # Show a recurring rule
banana recurring edit <rule-id>    # Edit or pause a recurring rule
banana recurring delete <rule-id>  # Delete a recurring rule
```

## Payments

```bash
banana payments add                   # Add a payment
banana payments get <payment-id>      # Show a payment
banana payments restore <payment-id>  # Restore a deleted payment
```

### Adding payments

```bash
banana payments add --amount 20 --currency EUR \
  --from me --to Ana --date 2026-09-01 \
  --description "Settle up"
```

## Groups

```bash
banana groups                     # List groups
banana groups create              # Create a group
banana groups get <group>         # Show a group
banana groups members <group>     # List group members
banana groups activities <group>  # List group activities
```

### Creating groups

```bash
banana groups create --name "Lisbon trip" --currency EUR \
  --type travel --member Ana
```

## Friends & currencies

```bash
banana friends       # List friends
banana currencies    # List available currencies
```

## Account

```bash
banana me            # Show the authenticated user
banana login         # Sign in with browser
banana logout        # Revoke and delete credentials
banana doctor        # Check CLI, login, and agent skill
banana version       # Print installed version
banana upgrade       # Upgrade to latest version
banana update        # Alias for upgrade
banana uninstall     # Remove CLI and stored login
```

## Agent skill

```bash
banana skill install     # Install skill for detected agents
banana skill uninstall   # Remove the skill
```

Options:
```bash
banana skill install --agent claude    # Specific agent
banana skill install --all             # All supported agents
banana skill install --list            # Show supported agents
banana skill install --dir <path>      # Custom directory
banana skill install --force           # Replace modified skill
banana skill install --print           # Print without installing
```

## Output formats

| Flag | Description |
|------|-------------|
| `--json` | Print curated operational JSON |
| `--raw` | Print the complete API response |

Flags can appear before or after the command:

```bash
banana --json balance
banana balance --json
```

## Naming

Currencies, groups, and people can be referenced by name, code, or prefix:

```bash
banana groups get Lisbon          # Matches "Lisbon trip"
banana expenses add --paid-by me  # You
banana expenses add --split Ana=20
```

IDs also work. `me` always refers to you.

## Date formats

`--date` accepts:

```bash
--date 2026-09-16                    # Midnight UTC
--date 16-09-2026                    # DD-MM-YYYY also works
--date 2026-09-16T21:20:00           # With time (UTC)
--date 2026-09-16T21:20:00+02:00     # With timezone
```
