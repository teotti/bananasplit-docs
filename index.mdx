## For agents

BananaSplit is designed as an expense tracking layer for AI agents. Your agent can:

- Add expenses with amounts, currencies, dates, and splits
- Record payments between friends
- Check balances and activity
- Create and manage groups
- Search expenses and browse history

Install the skill for your agent:

```bash
npx skills add teotti/banana-cli --skill banana --global
```

Or install the CLI directly and run `banana skill install`.

## For humans

The same CLI works in your terminal. Install it, sign in through the browser, and manage expenses from the command line:

```bash
curl -fsSL https://github.com/teotti/banana-cli/releases/latest/download/install.sh | sh
banana login
banana balance
```

Data syncs across iOS, Android, and web.
