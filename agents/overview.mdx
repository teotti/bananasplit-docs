Connect your AI agent to BananaSplit for expense tracking. This guide covers everything from installation to your first expense.

## Step 1: Install the CLI

The agent skill requires the BananaSplit CLI. Install it first:

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    curl -fsSL https://github.com/teotti/banana-cli/releases/latest/download/install.sh | sh
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    irm https://github.com/teotti/banana-cli/releases/latest/download/install.ps1 | iex
    ```
  </Tab>
  <Tab title="npm / Bun">
    ```bash
    bun install -g @bananasplitapp/cli
    # or
    npm install -g @bananasplitapp/cli
    ```
  </Tab>
</Tabs>

Verify it installed:

```bash
banana --version
```

## Step 2: Sign in to BananaSplit

```bash
banana login
```

This opens your browser. Sign in to your BananaSplit account (or create one) and approve the connection. You only need to do this once — the agent uses your stored credentials.

Verify you're signed in:

```bash
banana me
```

## Step 3: Install the skill for your agent

<Tabs>
  <Tab title="All agents (auto-detect)">
    ```bash
    banana skill install
    ```
    Installs for Claude Code, Codex, Cursor, Gemini CLI, and opencode if their directories exist.
  </Tab>
  <Tab title="Claude Code">
    ```bash
    banana skill install --agent claude
    ```
  </Tab>
  <Tab title="Codex">
    ```bash
    banana skill install --agent codex
    ```
  </Tab>
  <Tab title="Cursor">
    ```bash
    banana skill install --agent cursor
    ```
  </Tab>
  <Tab title="Gemini CLI">
    ```bash
    banana skill install --agent gemini
    ```
  </Tab>
</Tabs>

## Step 4: Verify the setup

```bash
banana doctor
```

You should see:
- `ok` for CLI version
- `ok` for authentication
- `ok` for skill installation

## Step 5: Start using it

**Start a new agent session** (important — existing sessions won't load the new skill).

Try one of these prompts:

```
Check my BananaSplit balances.
```

```
Add a €30 lunch expense split equally with Ana.
```

```
Show my recent expenses on BananaSplit.
```

The agent will use the CLI to execute these actions on your account.

## What agents can do

| Action | Example prompt |
|--------|---------------|
| Check balances | "What do I owe on BananaSplit?" |
| Add expense | "Add a €42 dinner expense split with Ana" |
| Record payment | "I paid Ana €20" |
| List expenses | "Show my recent expenses" |
| Create group | "Create a group for our Lisbon trip" |
| Search | "Find all dinner expenses in the Trip group" |

## Supported agents

Works with any agent that has shell access:

- Claude Code
- Codex
- Cursor
- Gemini CLI
- opencode
- Any shell-enabled agent
