BananaSplit is the expense tracking layer for AI agents. Your agent can add expenses, record payments, check balances, and manage groups through the CLI.

## How it works

1. **Install the skill** — one command adds BananaSplit capabilities to your agent
2. **You sign in** — run `banana login` once in your terminal (not the agent)
3. **Agent operates** — your agent runs CLI commands on your behalf

The skill teaches your agent to use names, parse JSON output, split expenses correctly, and record payments. You keep control of authentication.

## Supported agents

The skill works with any agent that has shell access:

- Claude Code
- Codex
- Cursor
- Gemini CLI
- opencode
- Any shell-enabled agent

## Quick setup

<Tabs>
  <Tab title="Skills CLI">
    ```bash
    npx skills add teotti/banana-cli --skill banana --global
    ```
  </Tab>
  <Tab title="After installing CLI">
    ```bash
    banana skill install
    ```
    Installs for all detected agents automatically.
  </Tab>
</Tabs>

Then sign in:

```bash
banana login
```

Start a new agent session and ask: **"Use BananaSplit to check my balances."**

## What agents can do

| Action | Example prompt |
|--------|---------------|
| Check balances | "What do I owe?" |
| Add expense | "Add a €42 dinner expense split with Ana" |
| Record payment | "I paid Ana €20" |
| List expenses | "Show my recent expenses" |
| Create group | "Create a group for our Lisbon trip" |
| Search activity | "Find all dinner expenses in the Trip group" |
