title: Example prompts
description: Prompts that work well with the BananaSplit skill.
---

These prompts demonstrate what you can ask your agent to do with BananaSplit.

## Getting started

Start with these to verify the skill is working:

```
Use BananaSplit to check my balances.
What do I owe on BananaSplit?
Show my BananaSplit friends.
```

## Checking balances

```
What's my balance with Ana?
Who owes me money?
What do I owe across all groups?
Show the balance breakdown for the Lisbon trip group.
```

## Adding expenses

```
Add a €42 dinner expense paid by me, split equally with Ana.
I paid €100 for the hotel. Split it between me, Ana, and João.
Add a recurring monthly expense of €50 for the Netflix subscription.
Record a €15 coffee expense from yesterday in the Office group.
```

## Recording payments

```
I paid Ana €20 to settle up.
Record that João paid me €50.
Mark Ana's €30 debt as paid.
```

## Listing and searching

```
Show my recent expenses.
Find all expenses from the Lisbon trip.
Search for dinner expenses in the last month.
Show recurring expenses.
List the 10 largest expenses.
```

## Groups

```
Create a group called "Road trip" with EUR currency.
Add Ana to the Road trip group.
Show members of the Lisbon trip group.
What's the activity in the Office group?
Show all my groups.
```

## Editing and deleting

```
Change the title of expense [ID] to "Birthday dinner".
Update the amount on expense [ID] to €75.
Delete expense [ID].
Restore the expense I just deleted.
```

## Complex operations

```
Add a €200 dinner expense to the Lisbon trip, I paid,
split €80 to me, €60 to Ana, €60 to João.

Show me all expenses from last week sorted by amount.

Create a group for our apartment with monthly defaults,
add the roommates, and record this month's utilities.
```

## Tips

- **Use names** — "Ana" instead of user IDs
- **Use group names** — "Lisbon trip" instead of group IDs
- **Be specific about splits** — "split equally" or provide amounts
- **Specify currencies** — "€42" or "--currency EUR"
- **Mention dates** — "yesterday", "2026-09-15", or let it default to today
