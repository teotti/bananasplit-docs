These are real interactions showing how AI agents work with BananaSplit.

## Adding an expense

**Prompt:**
```
Add expense "Meat" 120.34€ yesterday on BBQ Legends group
```

**Agent runs:**
```bash
banana expenses add --title Meat --amount 120.34 \
  --currency EUR --group "BBQ Legends" --date 2026-09-20
```

**Result:**
```
Added Meat — €120.34, 2026-09-20, group BBQ Legends, paid by you.

Split equally three ways (€40.11 each): Diogo Ferreira, Paulo, Cláudia.
```

## Listing expenses

**Prompt:**
```
List the last expenses on BBQ Legends group
```

**Agent runs:**
```bash
banana expenses list --group "BBQ Legends" --json
```

**Result:**

## Tips

- **Use natural language** — the agent translates to CLI commands
- **Use names** — "Ana" not user IDs, "Lisbon trip" not group IDs
- **Specify currencies** — "€42" or "42 EUR" or "--currency EUR"
- **Mention dates** — "yesterday", "last Monday", or "2026-09-15"
- **Be specific about splits** — "split equally" or "I paid €30, Ana paid €20"
