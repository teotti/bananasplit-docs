## URL QR code

### cURL

```bash
# SVG output
curl "https://bananasplit.net/api/qr-code?type=url&url=https://example.com&format=svg" \
  -o qr.svg

# JSON with both formats
curl "https://bananasplit.net/api/qr-code?type=url&url=https://example.com&format=json"

# Custom colors
curl "https://bananasplit.net/api/qr-code?type=url&url=https://example.com&color=7b260f&background=ffe66f&format=svg"
```

### JavaScript

```javascript
const response = await fetch(
  'https://bananasplit.net/api/qr-code?' + new URLSearchParams({
    type: 'url',
    url: 'https://example.com',
    format: 'json'
  })
);

const { svg, png } = await response.json();
```

### Python

```python
import requests

response = requests.get('https://bananasplit.net/api/qr-code', params={
    'type': 'url',
    'url': 'https://example.com',
    'format': 'svg'
})

svg_content = response.text
```

## Wi-Fi QR code

```bash
curl -X POST "https://bananasplit.net/api/qr-code" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "wifi",
    "ssid": "MyNetwork",
    "password": "secret123",
    "encryption": "WPA",
    "format": "svg"
  }'
```

## Custom styling

### BananaSplit brand colors

```bash
curl "https://bananasplit.net/api/qr-code?type=url&url=https://bananasplit.net&color=7b260f&background=ffe66f&corners=rounded&format=svg"
```

### With banana logo

```bash
curl "https://bananasplit.net/api/qr-code?type=url&url=https://bananasplit.net&logo=banana&format=svg"
```

### Large print-ready

```bash
curl "https://bananasplit.net/api/qr-code?type=url&url=https://example.com&size=2048&format=png" \
  -o qr-print.png
```

## Using with agents

AI agents can generate QR codes inline:

```
Generate a QR code for https://bananasplit.net using the QR Code API
```

The agent will use the API to create the code and can embed it in responses or save to files.

## Error handling

```javascript
const response = await fetch('https://bananasplit.net/api/qr-code?type=url&url=invalid');

if (!response.ok) {
  const error = await response.json();
  console.error(error.code, error.hint);
  // INVALID_URL, "URL must start with http:// or https://"
}
```

## Rate limit handling

```javascript
const response = await fetch('https://bananasplit.net/api/qr-code?...');

if (response.status === 429) {
  const retryAfter = response.headers.get('Retry-After');
  await new Promise(r => setTimeout(r, retryAfter * 1000));
  // retry
}
```
