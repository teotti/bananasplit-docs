## Base URL

```
https://bananasplit.net/api/qr-code
```

## URL QR codes

### GET request

```
GET /api/qr-code?type=url&url={encoded-url}&format={format}
```

Shortcut:

```
GET /api/qr-code/url?url={encoded-url}&format={format}
```

### POST request

```bash
POST /api/qr-code
Content-Type: application/json

{
  "type": "url",
  "url": "https://example.com",
  "format": "svg"
}
```

|-----------|------|-------------|
| `type` | string | QR type: `url`, `wifi`, `vcard`, `email`, `sms`, `text` |

### Styling

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `color` | hex | varies | Foreground color (6 digits, no `#`) |
| `background` | hex | varies | Background color (6 digits, no `#`) |
| `logo` | string | `none` | `banana` or `none` |
| `corners` | string | `square` | `square` or `rounded` |

### Output

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `format` | string | `json` | `json`, `svg`, or `png` |
| `size` | integer | 256 | Image size in pixels (128–2048) |

## Response formats

### JSON

```json
{
  "svg": "<svg>...</svg>",
  "png": "data:image/png;base64,..."
}
```

### SVG

Returns raw SVG content with `Content-Type: image/svg+xml`.

### PNG

Returns binary PNG with `Content-Type: image/png`.

## Response headers

```
Cache-Control: private, no-store
```

## Error responses

### 400 Bad Request

```json
{
  "error": "Invalid URL",
  "code": "INVALID_URL",
  "hint": "URL must start with http:// or https://"
}
```

Check `code` and `hint`, correct the request, retry once.

### 413 Payload Too Large

Content exceeds limits. Shorten the payload or encode a URL that points to the full data.

### 422 Unprocessable Entity

Valid JSON but invalid QR content. Check field constraints.

### 429 Too Many Requests

Rate limited. Wait for the duration in `Retry-After` header.

## Rate limits

- 60 requests per minute per caller per edge location
- Distributed across Cloudflare's network
