## Install the CLI

<Tabs>
  <Tab title="macOS / Linux">
    ```bash
    curl -fsSL https://github.com/teotti/banana-cli/releases/latest/download/install.sh | sh
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    irm https://github.com/teotti/banana-cli/releases/latest/download/install.ps1 | iex
    ```
  </Tab>
  <Tab title="Bun / npm">
    ```bash
    bun install -g @bananasplitapp/cli
    ```
  </Tab>
</Tabs>

## Sign in

```bash
banana login
```

The CLI prints a code and opens your browser. Confirm the code matches, approve the login, and you're set. No passwords or API keys to manage.

## Check your balances

```bash
banana balance
```

Lists what you owe and what others owe you across all groups and friends.

## Add an expense

```bash
banana expenses add --title "Dinner" --amount 42 --currency EUR \
  --paid-by me --split me=21 --split Ana=21
```

## For agents

If you're setting up an AI agent, install the skill instead:

```bash
npx skills add teotti/banana-cli --skill banana --global
```

Or after installing the CLI:

```bash
banana skill install
```

Start a new agent session and ask: **"Use BananaSplit to check my balances."**
