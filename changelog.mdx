Release notes for the BananaSplit CLI. For full details, see [GitHub Releases](https://github.com/teotti/banana-cli/releases).

<Update label="October 7, 2026" description="v0.4.0">
  - Added opt-in staging end-to-end test suite
</Update>

<Update label="September 25, 2026" description="v0.3.5">
  - Added `-v` as alias for `--version`
  - Fixed paginated rule handling
  - Added `--notify-me` flag for expense creation notifications
</Update>

<Update label="September 21, 2026" description="v0.3.4" tags={["Feature"]}>
  - **Recurring expenses** — `banana recurring add/list/edit/delete`
  - **Restore commands** — `banana expenses restore`, `banana payments restore`
  - **Delete expenses** — `banana expenses delete`
</Update>

<Update label="September 18, 2026" description="v0.3.1">
  - Enhanced `--date` flag to accept time values (e.g., `2026-09-16T21:20:00+02:00`)
</Update>

<Update label="September 18, 2026" description="v0.3.0" tags={["Feature"]}>
  - **Agent skill** — `banana skill install` for Claude Code, Codex, Cursor, Gemini CLI
  - **Health checks** — `banana doctor` to verify setup
  - **Auto-update** — `banana upgrade` to get latest version
</Update>

<Update label="September 11, 2026" description="v0.2.7" tags={["Feature"]}>
  - **Name-based lookups** — use names instead of IDs for currencies, groups, and people
  - `--paid-by Ana` instead of `--paid-by USER_ID`
</Update>

<Update label="September 10, 2026" description="v0.2.6">
  - Version reporting after updates
</Update>

<Update label="September 10, 2026" description="v0.2.5" tags={["Fix"]}>
  - Fixed macOS keychain access issues
  - Improved nested list drilling in interactive browser
</Update>

<Update label="September 9, 2026" description="v0.2.4" tags={["Fix"]}>
  - Bug fixes and stability improvements
</Update>

<Update label="September 8, 2026" description="v0.2.2">
  - Added version and run context to user-agent headers
</Update>
