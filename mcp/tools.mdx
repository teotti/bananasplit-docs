The BananaSplit MCP server exposes 26 tools for AI clients.

## Data conventions

Before using the tools, understand these conventions:

- **References are UUIDs** — use lookup tools (`list_friends`, `list_groups`, `list_currencies`) to find IDs
- **Amounts are decimal strings** — e.g., `"21.50"`, not `21.5` or `21`
- **List results are wrapped** — single lists return `{ items: [...] }`
- **Paginated results include cursor info** — `{ items: [...], nextCursor: "...", hasMore: true }`
- **Scopes** — all tools require `mcp:read`; creates, updates, deletes, and restores also require `mcp:write`

Get your account information.

**Parameters:** None

### `get_balance`

Get your total balance summary.

### `get_balance_users`

Get balances broken down by person.

**Parameters:** None

**Returns:** Balance details for each friend you have unsettled amounts with.

## Writing data

Creates and updates are **not idempotent**. If a write fails ambiguously (timeout, network error), don't automatically retry. Check the record or balances first to see if it went through.

Deletes are **soft** — records can be restored. The restore tools bring deleted records back. Restoring an already-active record is a no-op.

The `automated` boolean on `create_expense` and `create_payment` marks records as created by automation. This appears in the record's origin field.

## Not exposed

The following are not available through MCP:

- Uploads (receipt photos)
- Editing or deleting payments
- Admin tools
- Prompts and subscriptions

Use the app or CLI for these.

## Error handling

Tools return errors in this format:

```json
{
  "error": "Expense not found",
  "code": "NOT_FOUND"
}
```

Common error codes:
- `NOT_FOUND` — resource doesn't exist
- `INVALID_INPUT` — bad parameters
- `UNAUTHORIZED` — re-authenticate
- `FORBIDDEN` — no permission (check scopes)
