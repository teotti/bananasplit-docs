BananaSplit provides an MCP (Model Context Protocol) server that lets AI clients like Claude, ChatGPT, Grok, and Cursor connect directly to your expense data.

<Tip>Using Claude? BananaSplit is an approved connector. [Connect it from the Claude directory](https://claude.ai/directory/bananasplit) in two clicks.</Tip>

## What is MCP?

MCP is an open standard for connecting AI applications to external data sources and tools. Instead of copy-pasting data or using a CLI, your AI assistant connects directly to BananaSplit and can read your expenses, balances, and groups in real-time.

## Server URL

```
https://api.bananasplit.net/mcp
```

## Features

With the BananaSplit MCP server, AI clients can:

- **Check balances** — see what you owe and what's owed to you
- **Manage expenses** — list, create, edit, delete, and restore expenses
- **Record payments** — log settlements and restore deleted payments
- **View groups** — see group members, activity, and create new groups
- **Handle recurring expenses** — set up, edit, pause, and remove recurring rules
- **Look up references** — find friends, currencies, and categories

## Example prompts

- "Can you list my latest expenses?"
- "Add a €104 dinner at O Abel with Leo, I paid"
- "How much do I owe across all my groups?"
- "Looking at my groups and expenses, summarize my trips this year"

When you add an expense in a sentence, the AI works out who was there, how much it cost, and who paid, then splits it equally unless you say otherwise.

## Authentication

The MCP server uses OAuth with browser-based consent. When you first connect:

1. Your AI client opens a browser window
2. You sign in to BananaSplit (if not already)
3. You approve the connection
4. The client receives secure access

No API keys or tokens to manage manually.
